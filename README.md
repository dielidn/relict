# Реликт

Играбельный браузерный прототип PvPvE экстракшн-шутера. Мир, где метеорит промахнулся: гиганты вымерли от голода, а мелкие рептилии встали на задние лапы, сделали луки из веток и броню из листьев.

## Как играть

Открой `index.html` в браузере на компьютере (Chrome или Edge) или зайди на страницу GitHub Pages этого репозитория. Установка не нужна.

| Клавиша | Действие |
|---|---|
| W A S D | Бег |
| Мышь | Камера и прицел |
| ЛКМ | Атака |
| Shift | Рывок |
| Пробел | Прыжок |
| Q | Способность героя |
| E | Подобрать артефакт |
| Tab / 1–4 | Древо навыков матча |
| B | Улучшить оружие за золото |
| M | Звук |
| Esc | Пауза |

## Тест нового окружения

`canyon.html` — отдельная сцена «Ущелье» с новой, менее угловатой графикой: замшелые скалы, ручей, пальмы, папоротники, трава на ветру и светящиеся кристаллы. По ней можно гулять (WASD, мышь, F — полёт). На GitHub Pages она открывается по адресу `/canyon.html`.

## Что есть в прототипе

- Три героя: лягушка-древолаз (клинок, прыжок), реснитчатый геккон (лук, корковая броня), хамелеон (копьё, невидимость).
- Low-poly джунгли с плато, водопадом, озером и гротом.
- Насекомые, элитные богомолы и босс — реликтовая сколопендра.
- Два отряда-соперника под управлением ИИ.
- Древо навыков и улучшение оружия во время матча.
- Эвакуация через лиану, лавка между матчами, локальная рейтинговая таблица.
- Процедурная музыка: спокойная при фарме, боевая в схватках.

Мультиплеера пока нет: соперники — боты, прогресс хранится в браузере.

Сделано на [three.js](https://threejs.org/).
