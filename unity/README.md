# Реликт — прототип на Unity

Скрипты игрового прототипа. В проекте Unity они лежат в `Assets/_Relict/Scripts`, сцена матча — `Assets/_Relict/Scenes/Prototype.unity`.

## Как играть

Откройте сцену `Prototype` и нажмите Play. На стартовом экране выберите героя и нажмите «В джунгли».

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Shift | Бег |
| Пробел | Прыжок |
| ЛКМ | Атака: меч у лягушки, выстрел у геккона |
| ПКМ | Прицел (геккон) |
| Q | Способность: Прыжок с ударом по площади (лягушка), Корковая броня −70% урона (геккон) |
| Ctrl | Перекат (лягушка) |
| 1–4 | Навыки при повышении уровня |
| Esc | Пауза |

Цель матча (7 минут): собрать артефакты, пережить насекомых и соперников-ящериц и простоять 6 секунд в круге лианы. Лиана раскрывается через 2 минуты после начала. Золото и цена артефактов идут в казну лагеря, на неё на стартовом экране покупаются улучшения оружия.

## Что в коде

| Файл | Что делает |
| --- | --- |
| `HeroController.cs` | Управление, анимации, атаки и способности героев |
| `ThirdPersonCamera.cs` | Камера с третьего лица, столкновения со стволами, тряска |
| `Health.cs`, `Core.cs` | Здоровье, урон по области, материалы и эффекты |
| `Projectile.cs` | Стрелы |
| `EnemyAI.cs` | Муравьи, жуки и мини-босс Богомол-Страж, собранные из примитивов |
| `RivalAI.cs` | Отряд соперников: охотятся за артефактами, стреляют и эвакуируются |
| `Pickup.cs` | Золото, целебные споры, артефакты |
| `MatchManager.cs` | Цикл матча, спавн, волны, эвакуация, интерфейс, лавка, рейтинг |
