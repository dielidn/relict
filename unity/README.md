# Реликт — прототип на Unity

Скрипты игрового прототипа. В проекте Unity они лежат в `Assets/_Relict/Scripts`, сцена матча — `Assets/_Relict/Scenes/Prototype.unity`.

## Как играть

Откройте сцену `Prototype` и нажмите Play. На стартовом экране выберите героя и нажмите «В джунгли».

| Клавиша | Действие |
| --- | --- |
| WASD | Движение |
| Shift | Бег |
| Пробел | Прыжок, в воздухе — второй прыжок |
| ЛКМ | Атака. Лягушка: серия из трёх ударов (третий — крит), в воздухе — удар с неба. Геккон: удерживайте, чтобы натянуть лук |
| ПКМ | Прицел (геккон) |
| Q | Способность: Прыжок с ударом по площади (лягушка), Корковая броня −70% урона (геккон) |
| Ctrl или C | Уворот (2 заряда, неуязвимость). На бегу — подкат, сбивающий врагов. Уворот в последний момент — «идеальный»: замедление и крит следующей атакой |
| Tab | Улучшение героя: навыки и снаряжение за золото матча |
| 1–4 | Быстро изучить навык |
| Esc | Пауза |
| F11 | Полный экран (в собранной игре) |

Режим — дуэль на Л-образной карте. Вы стартуете с южного конца «Л», бот-соперник — с западного. На каждой полосе три зоны: муравьи, божьи коровки и мини-босс Богомол-Жнец. Зачистили зону — барьер из лиан падает и открывает путь дальше. На сгибе «Л» арена с Богомолом-Стражем: кто его убьёт, получает Сердце Реликта (+30% урона, +60 здоровья). Побеждает последний выживший. Через 8 минут все барьеры падают сами, через 12 минут на арене начинается ядовитый туман.

Существа (материалы, анимации, префабы) собираются из меню **Tools → Relict → Build Creatures**. Карта собирается заново из меню **Tools → Relict → Build L Map** (при открытой сцене Prototype).

## Что в коде

| Файл | Что делает |
| --- | --- |
| `HeroController.cs` | Управление, анимации, атаки и способности героев |
| `ThirdPersonCamera.cs` | Камера с третьего лица, столкновения со стволами, тряска |
| `Health.cs`, `Core.cs` | Здоровье, урон по области, материалы и эффекты |
| `Projectile.cs` | Стрелы |
| `EnemyAI.cs` | Муравьи, божьи коровки, Богомол-Жнец и Богомол-Страж на моделях со скелетом |
| `RivalAI.cs` | Отряд соперников: охотятся за артефактами, стреляют и эвакуируются |
| `Pickup.cs` | Золото, целебные споры, артефакты |
| `MatchManager.cs` | Цикл матча, спавн, волны, эвакуация, прокачка, лавка, рейтинг |
| `MatchManager.UI.cs` | Весь интерфейс: меню, HUD, Tab-улучшения, настройки, пауза, итоги |
| `GameSettings.cs`, `SFX.cs` | Настройки игрока и синтезированные звуки |

Шрифты интерфейса: Russo One и PT Sans (SIL Open Font License), лежат в `Assets/_Relict/Art/Fonts`.
